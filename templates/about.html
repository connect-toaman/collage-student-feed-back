About the Project

College Student Feedback Sentiment Analysis

What is the purpose?

The application uses Natural Language Processing (NLP) and machine learning to automatically classify written student feedback into Positive, Neutral, and Negative categories. This helps educational institutions quickly gauge student satisfaction across various departments and services without manually reading thousands of responses.

Processing Pipeline

Student Feedback

Raw text input submitted by the user.

↓

Text Preprocessing

Noise removal, tokenization, lemmatization, and negation preservation using NLTK.

↓

TF-IDF

Vectorizing the text to evaluate term frequency across the dataset.

↓

Logistic Regression

A trained statistical model calculates the probability of each class.

↓

Sentiment Classification

The highest probability determines the final predicted sentiment.
